### כללי עריכה בקבצי YAML
- **ההזחה (רווחים בתחילת שורה) חשובה** – שמרו על אותה הזחה כמו בשורות שמסביב. רווחים בלבד, לא טאב.
- טקסט שיש בו נקודתיים ואחריהן רווח (`: `) – עטפו במירכאות כפולות: `"TODO: טקסט"`.
- `**מילים**` = טקסט מודגש (בשדות שתומכים בזה, למשל פסקאות הילדים).
- `todo: true` = תוכן זמני. אחרי שמילאתם תוכן אמיתי – שנו ל-`false` או מחקו את השורה.
- אם משהו לא תקין, `npm run build` ייכשל עם הודעה שמציינת את הקובץ והשדה. האתר החי לא יישבר – Netlify פשוט לא יעלה גרסה שבורה.

## 3. החלפת וידאו הפתיחה

1. התקינו ffmpeg (פעם אחת): `brew install ffmpeg`
2. הריצו:
   ```bash
   npm run video -- ~/Desktop/clip.mov
   ```
   אופציות:
   - `--mobile ~/Desktop/vertical.mov` – קליפ אנכי נפרד לטלפונים
   - `--poster` – מחליף גם את תמונת הפתיחה בפריים מהווידאו
3. נוצרים `public/assets/video/hero.mp4`, `hero.webm`, `hero-mobile.mp4`. הווידאו מופיע אוטומטית ברענון הבא.

הווידאו נטען רק אחרי שהעמוד נטען, ולא נטען בכלל במצב חיסכון בנתונים, ברשת איטית, או כשהמשתמש ביקש "הפחתת תנועה" – אז מוצגת רק תמונת הפתיחה (`assets/images/hero/hero-poster.jpg`).

**מפרט מומלץ לצילום:** 8–15 שניות בלופ, אופקי 16:9, לפחות 1080p, יציב, האקשן במרכז הפריים (בטלפון רואים רק את השליש האמצעי).

## 4. תמונות

שימו תמונות בתיקיות תחת `assets/images/`:

| תיקייה | שימוש |
|---|---|
| `gallery/` | הגלריה – כל תמונה בתיקייה מוצגת אוטומטית. הסדר לפי שם הקובץ: `01-…`, `02-…` |
| `coach/` | ראש המועדון (שם הקובץ מוגדר ב-`coach.yaml`) |
| `kids/` | תוכנית הילדים (מוגדר ב-`kids.yaml`) |
| `disciplines/` | תמונה לכל תחום (מוגדר ב-`disciplines.yaml`, שדה `image`) |
| `testimonials/` | תמונות ממליצים (שדה `photo`) |
| `instagram/` | תמונות גיבוי לסקשן האינסטגרם (אם ריק – משתמשים בגלריה) |
| `hero/` | תמונת הפתיחה |
| `brand/` | לוגו ותמונות מותג |

אחרי שהוספתם תמונות:
```bash
npm run images
```
הסקריפט מסובב לפי הטלפון, **מוחק מידע מוסתר (כולל מיקום GPS)**, מקטין ל-2400px ומקודד מחדש. בזמן הבנייה Astro יוצר אוטומטית גרסאות AVIF/WebP בכל הגדלים – אין צורך להכין גדלים ידנית.

טיפים: JPG/PNG/WebP ברוחב 1600px ומעלה. HEIC מאייפון – ייצאו קודם ל-JPG. לכל תמונה בגלריה הוסיפו `alt` ב-`gallery.yaml` (חשוב לנגישות ולגוגל).

## 5. מערכת שעות

`src/data/schedule.yaml` – שורה לכל שיעור:

```yaml
- { day: 0, start: "17:30", end: "18:30", group: kids, discipline: kids, title: ילדים – קבוצה בוגרת }
```

- `day`: ‏0=ראשון 1=שני 2=שלישי 3=רביעי 4=חמישי 5=שישי 6=שבת
- `group`: ‏`kids` / `youth` / `adults`
- `discipline`: ‏`kids` / `muay-thai` / `mma` / `bjj` / `judo` / `fitness-women` / `fitness-men`
- ימים בלי שיעורים לא מוצגים. מסנני הגיל והתחום נבנים אוטומטית לפי מה שיש בקובץ.

## 6. אינסטגרם

הסקשן מציג את הפוסטים האחרונים של ‎@greenmount_mma בעיצוב של האתר. בחרנו ב-**Behold.so** כי הוא מטפל לבד בחידוש הטוקן ומארח את התמונות – בלי תחזוקה.

1. באפליקציית אינסטגרם: הגדרות ← סוג חשבון ← **חשבון מקצועי** (Creator או Business). חינם.
2. נרשמים ב-[behold.so](https://behold.so), מחברים את אינסטגרם ויוצרים **JSON Feed**.
3. מעתיקים את כתובת ה-feed ל-`src/config/site.ts` ← `instagram.beholdFeedUrl`.
4. בונים ופורסים.

כל עוד אין כתובת (או אם Behold לא זמין), מוצגות תמונות קבועות עם כפתור "עקבו אחרינו". הפיד נטען רק כשמגיעים לסקשן, ונשמר בזיכרון הדפדפן לשעה.

*חלופה:* Instagram Graph API ישירות דרך Netlify Function – בלי ספק חיצוני, אבל מחייב אפליקציית Meta, טוקן שפג כל 60 יום ומנגנון חידוש. אפשר להחליף בעתיד – רק `src/scripts/instagram.ts` משתנה.

## 7. טופס אימון ניסיון

הטופס עובד עם **Netlify Forms** – אין צורך בשרת.
- הפניות מופיעות ב-Netlify ← Site ← **Forms** ← `trial`.
- **התראה במייל:** Netlify ← Site configuration ← Forms ← Form notifications ← Add notification ← Email.
- הגנת ספאם: שדה מלכודת (honeypot) מובנה.
- אחרי שליחה מוצגת הודעת תודה בתוך העמוד. בלי JavaScript – מעבר לעמוד `/thanks`.
- כפתור "קבעו אימון ניסיון" בחלון של תחום מסוים בוחר מראש את התחום בטופס.

## 8. מדידה והמרות

מוגדר ב-`src/config/site.ts` ← `analytics`:
- **Google Analytics 4** – `G-VH93JV5K4J` (המזהה מהאתר הקודם).
- **Google Sheets** – אותו סקריפט מעקב כמו באתר הקודם, אותו פורמט נתונים.
- **Meta Pixel / TikTok Pixel** – מדביקים מזהה והם נטענים אוטומטית.

אירועים שנשלחים: `cta_trial_click`, `whatsapp_click` (עם מקור + הקשר), `generate_lead` (שליחת טופס), `phone_click`, `discipline_open`, `faq_open`, `social_click`, `navigation_click`. ב-Meta: ‏`Contact` / `Lead` / `ViewContent`.

הסקריפטים נטענים רק אחרי שהעמוד נטען (כדי לא להאט את האתר), ו**רק באתר החי** (גרסת production ב-Netlify). בפיתוח מקומי ובגרסאות תצוגה מקדימה לא נשלח כלום – כדי לא ללכלך את הנתונים. לבדיקה מקומית: `ANALYTICS=on npm run build`.

אחרי העלייה לאוויר: ב-GA4 סמנו את `generate_lead` ו-`whatsapp_click` כ-**Key events**.

## 9. פריסה ל-Netlify

**פעם ראשונה:**
```bash
npx netlify-cli login
npx netlify-cli link
```
(בוחרים את האתר הקיים greenmount-mma.)

**בכל עדכון:**
```bash
npm run deploy:preview
```
זה מעלה גרסת טיוטה לכתובת זמנית לבדיקה.

```bash
npm run deploy
```
זה מעלה לאתר החי.

**או דרך Git (מומלץ לטווח ארוך):** מעלים את הפרויקט ל-GitHub, וב-Netlify ← Site configuration ← Build & deploy ← Link repository. ההגדרות כבר ב-`netlify.toml` (פקודה `npm run build`, תיקייה `dist`, Node 22). כל push ל-main יעלה לאוויר אוטומטית, וכל Pull Request יקבל כתובת תצוגה מקדימה.
